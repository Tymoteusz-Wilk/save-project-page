01 / THE IDEA

Explore deliberately.

The agent keeps a question in view, requests a useful span of the video, then decides whether to inspect more or answer.

01 ↗
◫

Ask for a range

The model chooses a start and end time with QUERY RANGE(s, e). A broad first pass locates promising moments.

02 ↗
◎

Look where it counts

Scene-aware sampling allocates frames inside that range. Narrower queries reveal more temporal and visual detail; transcripts add audio context when available.

03 ✓
→

Refine or stop

The model uses each observation to zoom in, check a boundary, or return an answer. The loop stays intentionally small.

“

When does this help? The paper finds selective inspection most useful when answer-relevant events occupy a small part of a long video, where uniform sampling can miss them.

FRAME AT 01:47
MINERVA / SOUND + VISUAL SEARCH

What sound is happening when the girl wears a magician’s cape?

  1. 01 / SCAN

    Query the full 10:49 video to locate the girl and the cape.

  2. 02 / ZOOM

    Inspect roughly 01:15–02:42; the frame at 01:47 identifies the moment.

  3. 03 / ANSWER

    The nearby transcript says “Stop crying.” A baby is crying.

FRAME AT 00:59
MINERVA / COUNTING + TIME BOUNDARY

How many baskets are made between 00:22 and 01:00?

  1. 01 / TARGET

    Query the question’s interval, approximately 00:22–01:00.

  2. 02 / VERIFY

    Count makes near 00:30, 00:42, and 00:54. Inspect around 00:59–01:02 to check the next play.

  3. 03 / ANSWER

    The fourth play finishes after the cutoff. Three baskets count.
